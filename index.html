About Me

I'm Taha Amin, a penetration tester with an academic foundation in Cyber Security (BS). I specialise in web application and network security — thinking like an adversary to uncover weaknesses, then turning every finding into a clear, actionable fix.

My work is methodology-driven: I follow OWASP guidance for web testing, structure engagements around PTES, and map attacker behaviour to MITRE ATT&CK — so results are reproducible, prioritised and easy to act on.

When I'm not testing, I build my own tooling in Python — from OSINT automation to Tor-based scrapers for threat-intelligence research. The best way to defend a system is to understand exactly how it breaks.

// 04. methodology

How I Hack

Ethically, and by the book. Every engagement follows the Penetration Testing Execution Standard (PTES), with findings tested against OWASP and mapped to MITRE ATT&CK.

  1. phase_01

    Pre-engagement

    Agree scope, rules of engagement and written authorisation. No permission, no testing.

  2. phase_02

    Intelligence Gathering

    Passive and active recon — OSINT, DNS, subdomains, exposed services and the technology stack.

  3. phase_03

    Threat Modelling

    Identify high-value assets and likely adversaries, then plan realistic attack paths.

  4. phase_04

    Vulnerability Analysis

    Automated scanning plus manual validation to confirm what is actually exploitable — no false positives.

  5. phase_05

    Exploitation

    Safely prove impact — gaining access without disrupting production systems.

  6. phase_06

    Post-Exploitation

    Escalate privileges, move laterally and measure the real business impact of a compromise.

  7. phase_07

    Reporting

    Executive summary, CVSS-rated findings, proof of concept and clear remediation steps.

OWASP

Web and API testing guided by the OWASP Top 10 and the Web Security Testing Guide.

PTES

The Penetration Testing Execution Standard — a structured, seven-phase engagement lifecycle.

MITRE ATT&CK

A knowledge base of real-world adversary tactics and techniques for mapping attack paths.
